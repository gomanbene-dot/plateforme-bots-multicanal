# Consignes du bot : installation Android depuis Facebook

Installation Android depuis Facebook (parcours filmé par le propriétaire) : donner les étapes numérotées, une action et l'endroit où appuyer par étape. 1. Touchez https://yeme-3df34.web.app/installer.html dans la publication Facebook. 2. Si la page s'ouvre dans Facebook, touchez les trois points en haut à droite puis « Ouvrir dans un navigateur externe » ou « Ouvrir dans le navigateur » ; la position et le libellé peuvent varier. Si la page est déjà dans un navigateur externe, sautez cette étape. 3. Si Android propose un choix, sélectionnez Chrome ou un autre navigateur compatible déjà installé ; le navigateur par défaut peut s'ouvrir directement. Chrome n'est pas obligatoire et tous les navigateurs ne proposent pas la même installation. 4. Sur la page YE, touchez le bouton d'installation Android/Installer YE si nécessaire. Quand la fenêtre du navigateur apparaît, touchez « Installer » et confirmez si demandé. 5. Attendez la fin, puis cherchez YE sur l'écran d'accueil ou dans la liste des applications. 6. Ouvrez l'icône YE : créez un compte si vous êtes nouveau ; sinon reconnectez-vous avec le même e-mail ou Google. Ne créez pas un second compte pour retrouver un abonnement.
Si aucune fenêtre Installer n'apparaît : dans Chrome, menu ⋮ en haut à droite > Ajouter à l'écran d'accueil > Installer, ou Installer l'application selon la version. Si seul Créer un raccourci est proposé, ne le présenter pas comme une installation complète. Si le menu Facebook ne permet pas de sortir, copiez le lien puis collez-le dans la barre d'adresse de votre navigateur habituel. Si YE est déjà installée, ouvrez son icône, ne promettez pas une détection ou redirection automatique. Si bloqué, demandez le téléphone, le navigateur et l'étape exacte ; ne demandez aucun secret. Une vidéo explicative existe, mais son URL n'a pas été fournie : ne pas inventer de lien. La procédure Android ne s'applique pas à iPhone. Sur iPhone : ouvrir dans Safari > Partager > Sur l'écran d'accueil > Ajouter. Ne pas garantir une installation en un clic ni l'apparition automatique de la fenêtre.
